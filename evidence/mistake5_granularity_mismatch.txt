Trace Output:

Root Cause Analysis:
- `shift_agg` aggregated 15-minute readings to shift totals (sum = 32 readings * 18.5 kWh = 592.0 kWh).
- `compute_baseline` was passed `df_for_baseline = df.copy()`, which contained raw 15-minute intervals (mean = 18.5 kWh).
- Arithmetic compared shift-total actual (592.0 kWh) against interval baseline (18.5 kWh).
- Resulting false deviation: (592.0 - 18.5) / 18.5 * 100 = 3100%, causing every single normal period to be flagged as an anomaly.

Resolution:
- Changed `df_for_baseline` to point to `shift_agg`.
- Now comparing shift-total actual against historical shift-total baseline (mean = 592.0 kWh, deviation = 0.0%).
- All 36 unit tests passed cleanly after fix.
